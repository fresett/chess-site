Цель: 50 задач вместо 25 (маты в 1/2/3+, вилки, связки, сквозные удары, вскрытые шахи, превращения,
дебютные ловушки, эндшпиль) и новая страница задач.

## Что здесь
- `verify.py` — проверка задач на python-chess: решение работает, первый ход единственный,
  ответы соперника — лучшая защита. Запуск: `python -I -u verify.py . puzzles_src` → `puzzles_src.out.json`.
- `puzzles_src.py`, `puzzles_src2.py`, `puzzles_src4.py` — кандидаты; `puzzles_heavy.py` — две медленные
  (глубокий перебор, «Прорыв пешек» и «Слоновая ловушка»).
- `build.py` — собирает все `*.out.json` в `ladya/puzzles.py` (сортировка по сложности, номера 1…N).
- `site/` — готовая новая страница: `puzzles.js`, `puzzles.html`, `puzzles.css` (дописать в конец style.css),
  `test_puzzles.py.wip` (переименовать в test_puzzles.py и положить в tests/), `db_and_index.diff` — миграция 8 (сброс старых отметок «решено») и
  правки главной (число задач, тема задачи дня).
