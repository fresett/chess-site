# «Ладья» — сайт шахматного клуба

Онлайн-игра с живыми соперниками (без WebSocket — работает на бесплатном PythonAnywhere), клубы и турниры
по швейцарской и круговой системе, игра с ботами и тренером Альбертом, задачи с рейтингом, доска анализа,
дебюты и чемпионы мира. Стек: Flask + SQLite + чистый JS.

## Что умеет сайт

**Игра**
- Онлайн: быстрый поиск соперника с контролем 1+0, 2+1, 3+0, 3+2, 5+0, 5+3, 10+0, 10+5, 15+10, 30+0;
  вызов конкретного игрока по нику или ссылкой-приглашением (её может принять и гость); реванш со сменой цветов;
  ничья, сдача, отмена до первых ходов; если соперник пропал больше чем на 30 секунд — можно забрать победу.
- Все ходы и часы проверяет сервер (python-chess): рокировка, взятие на проходе, превращение, 50 ходов, повторение.
- Премувы, стрелки и кружки правой кнопкой мыши, взятые фигуры и перевес, перемотка партии, зрители, PGN.
- Боты 200–2000, тренер Альберт, игра вдвоём на одном устройстве.
- Доска анализа: свободная расстановка, движок, импорт/экспорт PGN и FEN.

**Рейтинги**
- Клубный рейтинг (старт 100) — за партии с ботами и тренером, как раньше.
- Glicko-2 (как на lichess) отдельно для пули, блица, рапида, классики и задач. График рейтинга в профиле.
- Задача дня; рейтинг в задачах считается по первой попытке.

**Клубы и турниры**
- Клубы: описание, вступление по заявке / свободно / только по приглашению, ссылка-приглашение,
  заявки, удаление участников, тренеры клуба, рейтинг внутри клуба, турниры клуба.
- Турниры: швейцарская (жеребьёвка без повторных пар, с учётом цветов, bye при нечётном числе) или круговая система.
  Режимы: **онлайн** (партии создаются при жеребьёвке, результат записывается сам, неявка = поражение)
  и **очно** (тренер вводит результаты). Таблица с усечённым Бухгольцем, Бухгольцем, Бергером;
  печатная версия таблицы и пар тура. Тренер может исправить результат, снять или вернуть игрока,
  добавить игрока вручную — в том числе без аккаунта (для очных турниров), отменить жеребьёвку тура.
- Уведомления (колокольчик): вызов на партию, начало тура, ответ на заявку в клуб.

## Роли

| Роль | Что может |
|---|---|
| `admin` | всё: админка `/admin` (пользователи, роли, блокировка, сброс пароля, клубы, турниры, жалобы, журнал входов) |
| `coach` | создаёт клубы и турниры, управляет своими (и клубами, где он назначен тренером) |
| `user` | играет, вступает в клубы, записывается на турниры |

Роль назначается в админке или командой `python manage.py set-role НИК coach`.

## Первый администратор

Пароли **не хранятся в репозитории**. Создай администратора сам (на компьютере или в консоли хостинга):

```
python manage.py create-admin Elena                 # пароль спросит (ввод не виден)
python manage.py create-admin Kirill --must-change  # при первом входе попросит придумать свой пароль
ADMIN_PASSWORD='...' python manage.py create-admin Elena   # или пароль из переменной окружения
python manage.py set-role fresett owner             # владелец сайта (красный): может всё и один выдаёт роли
```

Если аккаунт уже есть — команда сделает его администратором.

## Запуск на своём компьютере

```
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000. База создаётся сама (`instance/chess.db`).

**Проверить онлайн одному:** открой второе окно в режиме инкогнито (Ctrl+Shift+N) — у него свои cookie.
В одном окне войди, во втором войди другим аккаунтом или нажми «Играть как гость», в обоих — «Найти соперника».

**Тесты:** `pip install pytest && python -m pytest` (жеребьёвка, права ролей, пароли, лимиты, онлайн-партия двумя клиентами…).

## Выкладка на PythonAnywhere (бесплатно)

1. Зарегистрируйся на https://www.pythonanywhere.com (тариф **Beginner**).
2. **Consoles → Bash**:
   ```
   git clone https://github.com/fresett/chess-site.git chess_site
   cd chess_site
   pip3 install --user -r requirements.txt
   python3 manage.py create-admin ТВОЙ_НИК
   ```
3. **Web → Add a new web app → Manual configuration** → самая новая версия Python.
4. На странице **Web** открой **WSGI configuration file**, сотри всё и вставь (вместо `ЛОГИН` — твой логин):
   ```
   import sys
   sys.path.insert(0, '/home/ЛОГИН/chess_site')
   from wsgi import application
   ```
5. **Static files**: URL `/static/`, Directory `/home/ЛОГИН/chess_site/static`.
6. Включи **Force HTTPS**, нажми **Reload**.

**Обновление сайта:** `cd chess_site && git pull && python3 manage.py migrate`, затем **Reload**.
Схема базы обновляется миграциями (таблица `schema_version`); перед обновлением делается копия
`instance/backup-before-vN-….db`, данные не теряются.

Раз в 3 месяца нажимай на вкладке **Web** «Run until 3 months from today», иначе бесплатный сайт уснёт.

## Обслуживание

| Задача | Команда |
|---|---|
| Список участников | `python manage.py users` |
| Ученик забыл пароль | Админка → Пользователи → «Сбросить пароль» (или `python manage.py reset-password НИК --must-change`) |
| Снять блокировку | `python manage.py unlock НИК` |
| Удалить участника | `python manage.py delete НИК` |
| Резервная копия | `python manage.py backup` (с проверкой целостности) |
| Проверка базы | `python manage.py check` |

Делай резервную копию хотя бы раз в месяц и скачивай её к себе (Files → instance).

## Безопасность

- Пароли хранятся только как хэш scrypt; минимум 8 символов, простые пароли (12345678, qwerty, йцукенгш…) не принимаются.
- Ограничение частоты: вход (по IP и по аккаунту), регистрация, API, общий лимит по IP; после 8 неверных паролей
  подряд вход в аккаунт закрывается на 15 минут. Журнал входов — в админке.
- CSRF-токен на всех POST, заголовки CSP / X-Frame-Options / Referrer-Policy / HSTS (по HTTPS),
  cookie HttpOnly + SameSite=Lax + Secure (на хостинге). Аватарки проверяются по содержимому (PNG/JPEG, до 150 КБ).
- Смена пароля или блокировка выкидывает аккаунт со всех остальных устройств.

### Про DDoS — честно

Приложение умеет отбиваться только от простого флуда: лимиты запросов и лёгкие ответы (опрос партии, где ничего
не изменилось, — пара байт). От настоящей DDoS-атаки маленький сайт на бесплатном хостинге приложением не защитить.
Полноценная защита — **Cloudflare** перед сайтом (бесплатный тариф), но для этого нужен **свой домен**
(адрес `*.pythonanywhere.com` подключить к Cloudflare нельзя):

1. Купи домен (например, `ladya-club.ru`) и добавь его в Cloudflare (Add site → Free).
2. У регистратора домена замени NS-серверы на те, что выдал Cloudflare.
3. На PythonAnywhere нужен платный тариф для своего домена: **Web → Add a new web app** с этим доменом;
   PythonAnywhere покажет CNAME-запись — добавь её в DNS Cloudflare (с оранжевым облаком «Proxied»).
4. В Cloudflare: SSL/TLS → **Full (strict)**; Security → включи Bot Fight Mode; при атаке — «Under Attack Mode».
5. В WSGI-файле перед `from wsgi import application` добавь `import os; os.environ["PROXY_HOPS"] = "2"`,
   чтобы сайт видел настоящий IP посетителя (Cloudflare + прокси PythonAnywhere) и лимиты работали правильно.

## Что внутри

- `app.py` — запуск; `wsgi.py` — для хостинга; `manage.py` — команды администратора.
- `ladya/` — сервер: `__init__.py` (фабрика), `db.py` (миграции), `security.py`, `accounts.py`, `online.py`,
  `clubs.py`, `tournaments.py`, `swiss.py` (жеребьёвка и тай-брейки), `glicko2.py`, `ratings.py`, `admin.py`,
  `notify.py`, `pages.py`, `puzzles.py`.
- `static/js/` — `chess.js` (движок и боты), `board.js` (доска, премувы, стрелки), `online.js`, `analysis.js`, `play.js` …
- `templates/` — страницы; `tests/` — тесты pytest.
- Данные: дебюты — lichess-org/chess-openings (CC0); фото чемпионов — Wikimedia Commons.
