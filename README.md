# «Ладья» — сайт шахматного клуба

Игра с ботами и тренером Альбертом, онлайн-игра с живым соперником (можно гостем),
игра вдвоём на одном устройстве, 25 задач, 300 дебютов, 18 чемпионов мира, рейтинг клуба.

## Как проверить онлайн-игру на одном компьютере

1. Запусти сайт (`python app.py`) и открой http://127.0.0.1:5000/online
2. Открой второе окно **в режиме инкогнито** (Ctrl+Shift+N) — у него свои «куки», это будет второй игрок.
3. В каждом окне войди (разными аккаунтами) или нажми «Играть как гость».
4. В обоих окнах нажми «Найти соперника» — партия начнётся сама.

Один и тот же аккаунт сам с собой не играет — поэтому нужно именно инкогнито или другой браузер.

## Запуск на своём компьютере

```
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000

## Выкладка в интернет (PythonAnywhere, бесплатно)

Сайт будет по адресу `https://ТВОЙ_ЛОГИН.pythonanywhere.com`.

1. Зарегистрируйся на https://www.pythonanywhere.com (тариф **Beginner** — бесплатный).
2. Вкладка **Files** → кнопка **Upload a file** → загрузи архив `ladya_hosting.zip`.
3. Вкладка **Consoles** → **Bash** → выполни:
   ```
   unzip ladya_hosting.zip -d chess_site
   pip3 install --user "chess>=1.10"
   ```
   (вторая команда ставит библиотеку проверки ходов для онлайн-игры)
4. Вкладка **Web** → **Add a new web app** → **Next** → **Manual configuration** →
   выбери самую новую версию Python → **Next**.
5. На той же странице **Web** найди строку **WSGI configuration file** и нажми на ссылку.
   Сотри всё содержимое файла и вставь (вместо `ТВОЙ_ЛОГИН` — твой логин):
   ```
   import sys
   sys.path.insert(0, '/home/ТВОЙ_ЛОГИН/chess_site')
   from wsgi import application
   ```
   Нажми **Save**.
6. Там же, в разделе **Static files**, добавь строку: URL `/static/`,
   Directory `/home/ТВОЙ_ЛОГИН/chess_site/static`.
7. Включи **Force HTTPS** и нажми большую зелёную кнопку **Reload**.

Готово! Открой свой адрес.

**Важно для бесплатного тарифа:** раз в 3 месяца заходи на вкладку **Web** и нажимай
**Run until 3 months from today**, иначе сайт уснёт.

## Обслуживание клуба

Команды выполняются в консоли **Bash** на PythonAnywhere (сначала `cd chess_site`):

| Задача | Команда |
|---|---|
| Список участников | `python manage.py users` |
| Ученик забыл пароль | `python manage.py reset-password НИК НовыйПароль` |
| Удалить участника | `python manage.py delete НИК` |
| Резервная копия базы | `python manage.py backup` |

Все данные (аккаунты, рейтинг, партии) лежат в файле `instance/chess.db`.
Делай резервную копию раз в месяц.

## Что внутри

- `app.py` — сервер (Flask): аккаунты, рейтинг, задачи, защита.
- `static/js/chess.js` — шахматный движок и боты; `engine-worker.js` — расчёты тренера в фоне.
- `static/js/play.js` — игра (боты, тренер Альберт, оффлайн), `training.js` — дебюты.
- `online.py` + `static/js/online.js` — онлайн-игра: поиск соперника, ходы через сервер, счётчик «на сайте».
- `templates/` — страницы.
- Данные: дебюты — lichess-org/chess-openings (CC0); фото чемпионов — Wikimedia Commons.
